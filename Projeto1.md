# Criando um sistema bancário com PYTHON
Este projeto contém a minha solução para o desafio “Criando um Sistema Bancário com Python”, proposto pela Digital Innovation One. A base do código foi fornecida durante as aulas, com algumas adaptações feitas por mim. O objetivo foi desenvolver um sistema bancário simples em Python, com funcionalidades como criação de conta, depósito, saque e visualização de extrato. O projeto foi uma excelente oportunidade para praticar a lógica de programação e aplicar conceitos fundamentais da linguagem Python no contexto de um sistema financeiro.
